# Cyber Teacher Academy — Android APK Project

This is an Android Studio/Gradle project wrapping the complete web prototype in a native Android WebView.

## Structure
- `app/src/main/java/.../MainActivity.java` — Android entry point
- `app/src/main/assets/index.html` — UI and lesson player
- `app/src/main/assets/content.json` — 24 lesson + quiz content
- `app/src/main/assets/assets/teacher_voice.mp3` — supplied teacher voice audio
- `app/build.gradle` — Android build configuration

## Build
Open this folder in Android Studio and let Gradle sync. Then:
Build → Generate App Bundles or APKs → Generate APKs.

A Gradle wrapper binary is intentionally not included because it must be generated by the local Android/Gradle toolchain.
